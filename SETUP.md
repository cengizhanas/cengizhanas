## Setup

1. Create a public GitHub repository with the exact same name as your GitHub username.

2. Upload:
   - README.md
   - assets/cengizhan-header.svg
   - assets/build-spectrum.svg
   - .github/workflows/snake.yml

3. Replace every occurrence of:
   __GITHUB_USERNAME__
   with your real GitHub username.

4. Enable Actions.

5. Run:
   Actions → Generate contribution flow → Run workflow

6. Optionally add LinkedIn / portfolio links at the bottom of README.md.
